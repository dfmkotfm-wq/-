## Аннотация

В данном исследовании решается задача ... (краткое описание проблемы). Предлагаемый подход основан на ... (основная идея). Результаты показывают улучшение ... (главный вывод).

## Структура репозитория

- `/data` – исходные и обработанные данные.
- `/scripts` – программный код для воспроизведения расчётов.
- `/results` – графики, таблицы, числовые результаты.
- `/thesis` – текст диссертации (PDF/LaTeX).

## Как использовать

Для воспроизведения результатов выполните инструкции в файле `инструкция.md`.
